# Campus To Code

"Create a professional, modern, and responsive personal portfolio website for a B.Tech student. The website must include a sticky navigation bar and the following sections:

Home: A hero section with a welcoming headline and a brief introduction.

About Me: A section detailing my background and passion for technology.

Education: A section showing my current B.Tech degree.

Skills: A visually appealing grid or list showing my technical and soft skills.

Projects: Cards displaying my completed projects with placeholder text for descriptions.

Certifications/Achievements: A section highlighting my awards and certificates.

Contact: A simple contact form with fields for name, email, and message. Please also include highly visible icon links to my GitHub and LinkedIn profiles in the footer and header."
